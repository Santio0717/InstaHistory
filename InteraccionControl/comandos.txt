💻 🧩 COMANDOS
🟡 1. Iniciar WebSocket (Node)

Ve a la carpeta donde está tu server:

cd ~/Code/Control/Frontend/js
node server.js

👉 Debes ver algo como:

Servidor WebSocket corriendo en puerto 8080

🔵 2. Servidor web (Three.js)

Desde la carpeta del frontend:

cd ~/Code/Control/Frontend
npx serve .

👉 o si usas python:

python3 -m http.server 3000

🟢 3. Script Python (control)

Activa tu entorno:

cd ~/Code/Control
source venv/bin/activate

Luego:

python input.py
